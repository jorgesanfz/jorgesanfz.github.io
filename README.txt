Jorge Sanchis - portfolio and CV

Open index.html in a browser. All fonts and images are included locally.
Keep the CV files alongside index.html for the download buttons to work.
To serve locally: python3 -m http.server 8000
Then open http://localhost:8000

Contents: HTML portfolio, local fonts, portrait, one-page PDF CV, plain-text CV.
No build step, API key, account or package installation is required.
